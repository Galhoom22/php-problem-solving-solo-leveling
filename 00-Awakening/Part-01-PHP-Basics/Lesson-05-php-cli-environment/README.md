# Lesson 05 — PHP CLI Environment (Repo Gym)

Status: Not cleared  
Competency map: HackerRank PHP (Basic) — PHP Environment (adapted)

## Learn
This gym runs on the **CLI**, not a full LAMP install:

- Install PHP 8.4+ / target 8.5 (`php -v`)
- Run files: `php playground.php` / `php path/to/solution-1.php`
- No Apache/Nginx required to clear Gates
- No MySQL required for the PHP-fit climb

Web server + database setup is useful for backend jobs, but it belongs to a **sibling web/backend track** — not Gate spam here.

## CHECK
Run `php -v` and `php playground.php`. What version do you see?

## Practice
Confirm `playground.php` prints a System line. Optionally note your OS + PHP version in `notes.md`.
