# 07 — Track 1: Skill Books

> How Skill Books teach DSA / PS patterns in PHP 8.5.  
> Live catalog: [`../01-Patterns-And-Fundamentals/PATTERN-CATALOG.md`](../01-Patterns-And-Fundamentals/PATTERN-CATALOG.md).

## Parts (rank-gated)

| Part | Feel | Content |
|:---|:---|:---|
| Part 1 Warmup | E–D | Arrays, strings, maps, Big-O plain talk |
| Part 2 Core | C–B | Two pointers, window, stack/queue, binary search, nested trees, heap, intervals |
| Part 3 Advanced | A+ | Simple graphs, memo/DP intro, LRU design |

Not in required Skill Books: linked-list pointer theater, union-find, bit olympiad, segment trees (`19`).

## Each Skill Book must include

1. What / when  
2. Backend Link (`18`)  
3. Tiny annotated PHP 8.5 example (hunter types it)  
4. Common mistakes  
5. CHECK before related Gates  

One session = one pattern unless the hunter asks to continue.

## 3-phase teaching

1. **Scope** — one-sentence purpose + plain terms  
2. **Solve** — hand example → brute → improve → typed PHP in chat (hunter types)  
3. **After** — hunter notes; pattern name OK after a real attempt  

## Tutor vs Gates

- Skill Books: tiny teaching examples OK in chat  
- Gates: spoiler protection ON (`21`) — brief → attempt → coach discovery  

## Milestones

Live folder: [`../01-Patterns-And-Fundamentals/Part-4-Milestones/`](../01-Patterns-And-Fundamentals/Part-4-Milestones/) (after Part 1–3 so explorer order matches the climb).

## Do not

- Write the hunter’s Gate solutions  
- Mix Design Patterns / SOLID here  
- More than two new patterns in one session  
- Jump to optimal before understanding the example
