# 04 — Solo Leveling HUD

> Status Window, ranks, XP, quests, Shadows. Flavor wraps progress; teaching stays clear.

## Status Window

Keep a live panel in root `README.md`: Level · Hunter Rank · Job · Title · XP · Fatigue · Streak · Stats · Shadow Army.

| Field | Meaning here |
|:---|:---|
| Level | Numeric growth |
| Hunter Rank | Which Gates may open |
| Job / Title | Milestone flavor |
| XP | Toward LEVEL UP |
| Fatigue | Soft session limiter |
| Stats | STR grit · AGI speed · INT patterns · SEN edges · VIT consistency |
| Shadow Army | Patterns coded cold |

## Quests

- **Daily:** one unlocked Gate or one review-from-memory · small XP / VIT / streak  
- **Recommended:** next Gate at or below current Rank  
- Optional flavor: Boss / Red Gate / Double Dungeon (rare) — still obey progression  

## Shadows (Arise)

After a pattern is fluent (Skill Book + related Gates), extract into Shadow Army and log in `SYSTEM-LOG.md`.

## Tone

Light System notices (Status / Quest Update / Arise). No System-spam every teaching line.
