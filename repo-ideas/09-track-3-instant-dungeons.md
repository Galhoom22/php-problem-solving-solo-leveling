## 7. Track 3 Ideas — Instant Dungeons / Mock Raids

Inspired by `03-Final-Project`, but without building a ticketing system.

### The Idea
Instead of SupportDesk Lite:
- **Instant Dungeons**: timed sessions (45–60 minutes) — Solo Leveling style sudden raids.
- Or **Weekly Raid**: 3 Gates (Easy/Medium/Medium) in one session.
- Or **FAANG / Big Tech mocks**: talk aloud, clarify constraints, brute → optimize → code.
- Track 3 is the **Mock Gauntlet** required for graduation (`20-big-tech-faang-graduation.md`).
- The goal is proving interview readiness under time pressure — not shipping a product.
- Feel: the Gate appears, the timer starts, you clear alone.
- PHP is the training language inside mocks; Transfer Sprint (Track 4) handles company languages.

### Hunter Rank Unlock for Track 3
- B-Rank: unlock phone-screen lite mocks (required toward Big Tech Ready)
- A-Rank: unlock onsite-coding lite + mixed raids
- S-Rank+: unlock harder FAANG Ready dungeons + Transfer mocks
- National / Monarch Candidate: teach-back + weak-Gate cleanup

See graduation mock table in `20-big-tech-faang-graduation.md`.

Instant Dungeons grant XP (+150), AGI, and can act as Association rank gates.

### Mentorship Rules (Reuse)
The student writes all code. The mentor may:
- Explain requirements.
- Show short examples in chat.
- Review.
- Point out gaps.
- Help debug after the student shares code or error output.

The mentor must not:
- Write complete solution files.
- Build the session for the student.
- Turn the track into a design-patterns course.
- Open a mock by pasting a full solution (`21` still applies).

### Suggested Milestone Plan
```
Milestone 00 - Setup runner / playground.php (Hunter license)
Milestone 01 - Timed E/D-Gate (20 min)
Milestone 02 - Timed C-Gate (35 min)
Milestone 03 - Explain aloud without code (Shadow check)
Milestone 04 - Optimize a brute-force clear
Milestone 05 - Mixed raid (2 Easy + 1 Medium)
Milestone 06 - Debug a failed clear (Urgent Quest)
Milestone 07 - Write tests for a solution (PHPUnit optional)
Milestone 08 - Full Instant Dungeon mock (2 Gates)
...
```
