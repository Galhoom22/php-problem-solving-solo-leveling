# 01 — Core Idea

> AI load this with `00-mission-learn-and-solve.md` first.
> Purpose, motto, Solo Leveling promise, and sacred progression rule summary.

## Single purpose

This repository is dedicated to **one thing only**:

> **Problem Solving + DSA specialized for PHP 8.5 — as a Learn + Solve system.**

It is a **learning academy and a solving gym**, not a solutions dump.

- **Opening rule:** Gates are authored **without finished solutions first**; the AI explains what the problem wants, the hunter tries alone, then non-spoiler coaching (`21`)
- Solutions here are **PHP only** (PHP 8.5)
- PHP-specialized training — not language-agnostic DSA with PHP pasted on (`19`)
- Problems are curated from many platforms, then filtered for PHP fitness
- No full OOP / OOD / Design Patterns / Laravel courses here — sibling study repos
- Minimal PHP OOP only when DSA needs nodes (`ListNode`, `TreeNode`)

## Who it is for

- Absolute beginners (PHP + PS + DSA from zero)
- PHP hunters leveling interview strength
- Polyglots (Python/Java/JS/C++) using this as a DSA dojo, then transferring

Exit: **Big Tech Ready** / **FAANG Ready** (`20`) — honest that PHP is not the default FAANG live-coding language.

## Learn + Solve (mandatory duo)

Every item must support both:

1. **Learn** — teach the idea in plain language
2. **Solve** — hunter writes PHP 8.5 and explains

A Gate with only an answer is incomplete. A lecture with no practice is incomplete.

## Motto

> Learn the Skill → Enter the Gate → Write PHP 8.5 → Level Up → Arise.

## Why Solo Leveling?

Boring repos feel like homework. This gym uses a light System HUD (quests, Status Window, ranks) so progression stays visible and addictive — without replacing clear teaching.

## Sacred rule: Strict Difficulty Progression

> **Never place a harder Gate before an easier Gate in the required climb path.**

- Gate IDs ascend by lane: E → D → C → B → A → S → Side → Armor (`03`, `05`)
- Inside a pattern folder: easier before harder
- Optional Side Quests never rewrite the required climb order

## Success test

> If a total beginner only follows this repo in order, will they understand PHP + Problem Solving + DSA better after every rank — and become dramatically stronger?

If no → content is incomplete (usually missing teaching, or progression is broken).
