# Codeforces — Side Quests

> **Not** on the required PHP Hunter / Big Tech / FAANG climb.  
> Repo policy: Codeforces is **optional Side Quests only** after the PHP Fitness Filter  
> (`repo-ideas/02-multi-platform-sources.md`, `repo-ideas/19-php-fitness-filter.md`).

## Why Side Quest?

- Codeforces is CP/contest-first (often C++-centric judges and culture).
- Many CF problems fail the PHP-feeling test (heavy graphs, exotic structures, olympiad math).
- We import **only** a thin curated set of classic Div.2 A (and one light A+) drills that stay array/string/math-shaped.

## Import rule

Only add a Gate here if:

1. PHP Fitness Filter passes (arrays/strings/simple math/scans)  
2. Not a near-duplicate of a required Gate (or clearly labeled related)  
3. Source uses a concrete `https://codeforces.com/problemset/problem/C/I` URL  
4. You write a short System Brief — do not paste huge copyrighted statements  

## Do not import into this folder

- Div.2 D+/Hard graph CP packs  
- Segment trees / Fenwick / flows as core training  
- Problems that only shine with manual pointers / ultra-tight C++ I/O
