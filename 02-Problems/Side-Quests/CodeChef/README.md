# CodeChef — Side Quests

> **Not** on the required PHP Hunter / Big Tech / FAANG climb.  
> Repo policy: CodeChef is optional after the PHP Fitness Filter (`repo-ideas/02-multi-platform-sources.md`).

## Why Side Quest?

- CodeChef is contest-first (often C++/Java/Python-centric).
- The hub [Practice PHP](https://www.codechef.com/practice/php) does not publish a rich static PHP catalog (page is mostly empty / app-rendered).
- We still import **classic beginner problem-codes** that are PHP-solvable and feel PHP-fit as optional drills.

## Import rule

Only add a Gate here if:

1. PHP Fitness Filter passes  
2. It is not a near-duplicate of a required Gate (or clearly labeled related)  
3. Source uses a concrete `https://www.codechef.com/problems/CODE` URL
