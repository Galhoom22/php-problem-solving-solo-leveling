## System Brief
Given a non-empty string, return `[firstChar, lastChar]`.

Example: `"hunter"` → `["h","r"]`.

## What This Gate Is Testing
Safe indexing of string ends.

## Learn First (System Tutorial)
- Index `0` and last index via `strlen`
- Careful with empty strings (input is non-empty here)
