## System Brief
Remove all spaces from a string.

Example: `"8 j 8   mBliB8g  imjB8B8  jl  B"` → `"8j8mBliB8gimjB8B8jlB"`.

## What This Gate Is Testing
Strip spaces without breaking other characters.
