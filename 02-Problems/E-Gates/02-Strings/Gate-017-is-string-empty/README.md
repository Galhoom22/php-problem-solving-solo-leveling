## System Brief
Return true if a string is empty (`""`). A string of only spaces is NOT empty.

Examples: `isEmpty("") → true`, `isEmpty(" ") → false`.

## What This Gate Is Testing
Exact empty check (not trim).

## Learn First (System Tutorial)
- `=== ''` or `strlen === 0`
- Read Notes: whitespace is not empty here
