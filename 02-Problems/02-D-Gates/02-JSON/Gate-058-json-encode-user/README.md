## System Brief
w3resource-style JSON drill: given `name` (string) and `age` (int), return a JSON string `{"name":"...","age":...}` using `json_encode` on an assoc array (pretty-print not required).

Example: `name=Ada, age=36` → `{"name":"Ada","age":36}`.
