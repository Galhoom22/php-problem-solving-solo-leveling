## System Brief
Exercism-style: convert a phrase to its acronym (uppercase). Split on spaces and hyphens; handle underscores if present.

Example: `"Portable Network Graphics"` → `"PNG"`; `"Complementary metal-oxide semiconductor"` → `"CMOS"`.
