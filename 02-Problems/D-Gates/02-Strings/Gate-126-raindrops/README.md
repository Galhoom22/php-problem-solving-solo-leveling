## System Brief
Exercism classic: convert a number to a string by rules:
- divisible by 3 → append `Pling`
- by 5 → `Plang`
- by 7 → `Plong`
- none → return the number as string

Examples: `28` → `"Plong"`; `30` → `"PlingPlang"`; `34` → `"34"`.
