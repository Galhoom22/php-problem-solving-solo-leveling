## System Brief
Return a string with the multiplication table for `n` from 1 to 10, each line like `1 * n = …`, separated by newlines (no trailing newline required unless you document it).

Example shape for `n = 5`:
`1 * 5 = 5`
`2 * 5 = 10`
…
`10 * 5 = 50`
