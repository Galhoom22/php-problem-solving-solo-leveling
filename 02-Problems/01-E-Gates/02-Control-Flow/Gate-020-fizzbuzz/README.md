## System Brief
For each integer from 1 to `n`, return a list of strings:
- multiples of 3 and 5 → `"FizzBuzz"`
- multiples of 3 → `"Fizz"`
- multiples of 5 → `"Buzz"`
- otherwise the number as a string

Example: `n = 5` → `["1","2","Fizz","4","Buzz"]`.
