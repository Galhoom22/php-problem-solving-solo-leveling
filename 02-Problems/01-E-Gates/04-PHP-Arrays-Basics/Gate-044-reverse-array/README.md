## System Brief
Return a new list with elements reversed. Empty list → empty list.

Examples: `reverse([1, 2, 3, 4]) → [4, 3, 2, 1]`.

Prefer implementing the idea yourself before relying on `array_reverse` — then compare.

## What This Gate Is Testing
Reorder list elements.
