## Quick start

```bash
php -v            # PHP 8.5+
php playground.php
```

1. Read the Gate `README.md` (brief → examples → Backend Link).
2. Solve in `solution-1.php` — brute force first, then tighten.
3. Say Time / Space aloud; mark ✅ on the [Gate map](02-Problems/README.md).

No framework and no Composer required for the climb.
